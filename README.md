## 📌 О проекте

**LexAI Legal** — интеллектуальный сервис автоматизированного юридического аудита и пре-скоринга договоров компании. Система выявляет скрытые финансовые риски, внутренние правовые коллизии между разделами, несоразмерные штрафы и неустойки по **ст. 333 Гражданского кодекса РФ**, рассчитывает вероятность успеха в суде на основе практики **КАД Арбитр** и формирует официальный 3-колоночный протокол разногласий (**Redline**).

## 🎯 Архитектура MVP и ключевой функционал

В состав минимального жизнеспособного продукта (MVP) входит 8 сквозных экранов:

| № | Экран | Описание функциональности MVP | User Story |
|---|---|---|---|
| **01** | **Настройка рабочего пространства (Шаг 1)** | Инициализация компании, подтягивание реквизитов из ЕГРЮЛ по ИНН, выбор отраслевого риск-профиля. | `US-1.1` |
| **02** | **Профиль юриста (Шаг 2)** | Персонализация учётной записи юрисконсульта, привязка реквизитов доверенности на право согласования. | `US-1.2` |
| **03** | **Параметры проверки ИИ (Шаг 3)** | Конфигурация чувствительности проверок: тумблеры детекции коллизий, штрафов > 0.1%/день, предиктора судов. | `US-1.3` |
| **04** | **Главный реестр договоров и портфель** | Сводная таблица контрактов с риск-скорингом, фильтрами («Требуют внимания», «На согласовании»), drag & drop загрузкой. | `US-2.1`, `US-2.2`, `US-2.3` |
| **05** | **Сплит-скрин анализ договора A4** | Двухколоночный инспектор: слева оригинальный лист A4 с подсветкой строк, справа — карточки рисков с цитатами и безопасными редакциями. | `US-3.1`, `US-3.2`, `US-3.3` |
| **06** | **Редактор разногласий Redline & КАД Арбитр** | 3-колоночный протокол (Редакция контрагента \| LexAI \| Обоснование), судебный предиктор победы (84%) и ст. 333 ГК РФ. | `US-4.1`, `US-4.2` |
| **07** | **Дашборд аналитики рисков портфеля** | Тепловая матрица рисков по типам сделок, динамика выявления за 6 месяцев, рейтинг надёжности контрагентов. | `US-6.1` |
| **08** | **Корпоративный Playbook и доступ** | Матрица автоматических правил IF/THEN («Если штраф > 0.1% -> Заменить на 0.01%»), ролевой доступ и аудит 152-ФЗ. | `US-5.1` |

## 🎨 Дизайн-система проекта

Интерфейс спроектирован по канонам корпоративного UX/UI и стандартов доступности **WCAG 2.1 AAA**:
* **Светлая тема (Warm Linen & Terracotta):**
  * Фон: `#FAF9F5` (Warm Linen Canvas), карточки: `#FFFFFF` / `#F5F3ED`
  * Акцентный цвет: `#D97757` (Terracotta Accent), текст: `#141413`
* **Тёмная тема (Deep Obsidian):**
  * Фон: `#141413` (Deep Obsidian Canvas), карточки: `#1F1E1B`
  * Бордеры: `#2D2B26`, акцент: `#E06738`
* **Мобильная адаптация:** адаптивная сетка под дисплеи смартфонов 390×844 px.

## 🛠️ Стек технологий

* **Frontend:** Next.js 14 (React, TypeScript), Tailwind CSS, Headless UI, PDF.js
* **Backend:** Python 3.12, FastAPI (REST API, SSE-стриминг), Pydantic v2, python-docx
* **AI / NLP:** LangChain, BGE-M3 Embeddings, pgvector, открытые юридические модели
* **Database & Storage:** PostgreSQL 16 (metadata, audit log), MinIO S3 (PDF/DOCX хранилище)
* **DevOps & QA:** Docker, Docker Compose, Pytest (покрытие > 85%), GitHub Actions CI/CD
